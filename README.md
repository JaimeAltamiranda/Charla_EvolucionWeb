# Evolución Web – Grupo 1

##  Descripción del Proyecto

Este proyecto fue desarrollado para la sustentación del Grupo 1 sobre la evolución de la web. El objetivo es mostrar cómo han cambiado las páginas web desde la Web 1.0 hasta las aplicaciones modernas e interactivas actuales.

La demostración incluye una comparación entre:
- Página web tradicional (Web 1.0)
- Página web moderna interactiva

---

#  Temas Desarrollados

## Web 1.0
- Páginas estáticas
- Poco diseño visual
- Sin interacción dinámica
- Contenido informativo

## Web 2.0
- Interacción con usuarios
- Redes sociales
- Contenido dinámico
- Aplicaciones web modernas

## Web 3.0
- Web descentralizada
- Inteligencia artificial
- Blockchain
- Personalización avanzada

---

#  Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- Responsive Design
- Animaciones CSS

---

#  Objetivo de la Demostración

Mostrar las diferencias entre una página antigua y una página moderna en aspectos como:
- Diseño
- Interactividad
- Experiencia de usuario
- Adaptabilidad
- Rendimiento
